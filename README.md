# Lofhood

Sistema web de alertas georreferenciadas diseñado para mantener a la comunidad informada. Permite a los usuarios emitir y visualizar alertas de seguridad o de interés general dentro de un perímetro específico, respaldado por un sistema seguro de gestión de usuarios.

## 🚀 Características Principales

* **Alertas Georreferenciadas:** Sistema de emisión y visualización de alertas limitadas a un radio de acción de 3 km.
* **Autenticación Segura:** Registro e inicio de sesión de usuarios con almacenamiento de contraseñas encriptadas.
* **Recuperación de Acceso:** Módulo automatizado para la recuperación de contraseñas vía correo electrónico (integración con Gmail).

## 🛠️ Tecnologías Utilizadas

* **Backend:** PHP
* **Base de Datos:** MySQL
* **Entorno:** XAMPP
